# 单题独立程序

一题一文件，每个文件都能**单独运行**，自行读取附件、完成计算并把结果写入 `result/`。

| 文件 | 对应问题 | 输出 |
|---|---|---|
| `问题1_预热平衡阶段.py` | 问题一（0~1800 s，附录2 常物性） | `result/result1.xlsx`（温度、水分浓度） |
| `问题2_恒温干燥阶段.py` | 问题二（0~3 h，附录3 变物性） | `result/result2.xlsx`（温度、水分浓度） |
| `问题3_烘干时间.py` | 问题三（全域含水率事件判终点） | `result/result3.xlsx`（Sheet1，含临界时刻行） |
| `问题4_收缩模型.py` | 问题四（附件2 半径，材料坐标） | `result/result4.xlsx`（Sheet1，域外留空 + 药材表面列） |

## 运行

```bash
python solution/问题1_预热平衡阶段.py
python solution/问题2_恒温干燥阶段.py
python solution/问题3_烘干时间.py
python solution/问题4_收缩模型.py
```

- 可选参数为径向区间数 N，默认 320：`python solution/问题3_烘干时间.py 640`
- 路径按脚本位置解析，可在任意目录运行。
- 依赖：`numpy`、`scipy`、`openpyxl`（见项目根目录 `requirements.txt`）。
- 结果同时打印到终端（中心/表面值、临界时间等）。

## 模型要点（四个文件一致）

- 节点中心环形控制体有限体积：N 个径向区间、N+1 个节点，界面取节点中点，
  `r_{-½}=0`、`r_{N+½}=R₀`；界面导热/扩散系数取**调和平均**。
- 表面为 Robin 边界：`-k∂T/∂r = h_T(T_s-T_a)`、`-D∂C/∂r = h_C(C_s-C_a)`；
  表面节点恰位于 `r=R₀`，不再另加半网格阻力。
- 时间积分用 `scipy.integrate.solve_ivp` 的 BDF，`rtol=1e-8`，
  `atol_T=1e-8`、`atol_C=1e-10`，并传入稀疏 Jacobian 结构。
- 环境取附件1分段线性插值，4 h 之后用末 1 h 均值外推。
- 问题三、四以 `max C − 0.15` 为事件（`terminal=True, direction=-1`），
  事件后补积一段并用 `brentq` 独立复核临界时刻。

## 与主程序的关系

`src/drying_model/` 是完整工程（含配置、敏感性、收敛、守恒与验证报告）；
本目录是便于阅读与逐题运行的等价精简版。两者的结果在**四位小数上完全一致**
（浮点差异 ≤5×10⁻⁶，源于积分步序列不同）。
